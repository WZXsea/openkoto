# OpenKoto Desktop 0.12.0 PR-14 结构化正文编辑预发布版
## 发布定位
0.12.0 在 PR-13 工程候选基线上完成结构化正文编辑、稳定段落身份、版本历史与派生内容管理。本版仍属于 Apple Silicon 单架构预发布，不开启 Anki、Zotero、MinerU、OCR 或外部 MCP 集成。
## 主要能力
1. Reader 新增受约束块编辑器，支持段落、H2/H3、单层列表、引用、分隔线、粗体、斜体、行内代码和链接。
2. 支持插入、删除、拆分、合并、拖动、键盘移动、撤销重做和受控 Markdown 源文本。
3. 自动保存仅写恢复草稿；显式保存先返回块、句子、派生内容、批注和学习项影响。
4. 未修改块和句子保留 UUID；拆分、合并和跨块移动按稳定匹配规则保留身份，并记录 segment lineage。
5. 人工保存创建递增 revision，支持块级差异和恢复；恢复时可在同一 Backend 事务内保留当前草稿为 stale。
6. 翻译、读音和精讲按来源哈希维护 `current/stale`，旧结果保留且不自动调用模型。
7. PDF/EPUB 原件保持不可变，可建立独立编辑稿并在素材库分组展示。
## 数据与迁移
1. 新增 `material_blocks`、`material_revisions`、`material_edit_drafts`、`material_segment_lineage`、`material_relations` 和迁移报告表。
2. `materials.content` 变为事务内生成的兼容投影；文本素材禁止再走全量 segment 删除重建。
3. 旧素材使用 `is_new_paragraph` 组成块并保留 segment UUID；异常数据写入 `legacy_content_mismatch` 报告。
4. 文档提交使用 `base_revision`、`client_request_id` 和预览令牌；并发冲突返回 `409 material_revision_conflict`。
## 验证基线
1. Backend 真实 PostgreSQL 测试、迁移、多用户隔离、并发提交、稳定 ID、lineage 和草稿恢复通过。
2. Agent Worker 37 项、Desktop Rust 106 项库测试与全部集成测试通过。
3. Frontend 62 个测试文件、254 项测试、TypeScript 检查、生产构建和 PR-14 Playwright 流程通过。
4. PR-7～PR-13 历史回归链通过。
5. ARM64 packaged smoke、内置 PostgreSQL smoke、应用深度签名和 DMG 镜像完整性通过。
