# OpenKoto Desktop 0.10.0 PR-12

## 发布定位

0.10.0 是 Apple Silicon 预发布检查点，交付 PR-12 Assistant 可观察工作流。第一阶段保持独立边界，不连接 Anki、Zotero、MinerU、MCP 或其他外部写入目标。

## 主要改动

1. 新增全局 Assistant 任务中心和 Reader 内任务页。
2. 统一 queued、running、succeeded、failed、cancelled 状态机与持久化时间线。
3. 增加取消、重试 attempt/root lineage、输入快照、运行摘要、错误和输出版本。
4. 产物查看支持思维导图、Assistant 回答、结构化报告、文件与未知类型降级。
5. 任务可通过 SourceLocator 回到原文，或通过规范 learning item ID 回到学习工作台。
6. 应用内导航统一经过 action registry 和 Backend 审计；未登记与外部写动作被拒绝。

## 数据与安全

1. PostgreSQL 继续作为 task、event、artifact 和 action audit 在线事实源。
2. 本地仅保留 worker checkpoint 与 legacy import 输入。
3. 迟到 worker 事件不能覆盖终态，重试不覆盖原任务、日志或产物。
4. task、event、artifact 和 action audit 均按当前账户隔离。

## 验证

1. 隔离 PostgreSQL 下 Backend 全量测试通过。
2. agent-worker 37 项测试通过。
3. Desktop Rust 库与全部集成测试通过，其中一项完整字幕提取流程按环境条件忽略。
4. Frontend 57 个测试文件、227 项测试和生产构建通过。
5. Playwright 5 项通过，2 项按环境条件跳过。
6. PR-7～PR-11 历史回归链通过。
7. ARM64 `.app` 与 `.dmg` 经 ad-hoc 签名完整性、bundled PostgreSQL、Node、agent-worker 和 DMG 挂载检查。

## 已知边界

1. 预发布包未使用 Apple Developer 证书签名或公证，正式发行门禁由 PR-13 处理。
2. 多 Agent 编排、Anki/FSRS 同步与其他外部软件写入不在本版本范围内。
