# OpenKoto Desktop 0.12.4 PR-14 块拖动动效优化预发布版
## 发布定位
0.12.4 改善结构化正文编辑器的块拖动反馈和操作自由度，修复拖动完成后残留蓝色节点选中边框、拖动缺少内容预览，以及必须把指针移入正文才能排序的问题。
## 交互调整
1. 拖动落点仅根据有效块的纵向几何位置和指针 Y 坐标计算，不再依赖横向命中正文。
2. 按住手柄后可让指针始终停留在正文左侧，仅上下移动完成排序。
3. 超过 4 px 拖动阈值后显示跟随指针的半透明块预览，保留源块文字、结构、行内格式和尺寸。
4. 拖动时弱化源位置，并继续显示明确的插入落点线。
5. 释放、取消、按下 Escape、窗口失焦或组件卸载时，统一清理虚影、落点线、源块拖动态和旧手柄位置。
6. 拖动提交后使用文本光标，不再创建会产生蓝色边框的 `NodeSelection`；重排仍为单事务并保留撤销、重做能力。
## 验收证据
1. 组件测试覆盖纯纵向落点、虚影跟随、阈值控制、四类取消路径和非节点选择状态，共 24 项通过。
2. Playwright 从手柄按下后始终保持相同 X 坐标，仅纵向移动完成重排；拖动中验证虚影、源块弱化和落点线，释放后验证全部清理。
3. 前端 64 个测试文件、281 项测试，以及 Backend、Desktop Rust、agent worker、历史回归和 packaged smoke 全部通过。
