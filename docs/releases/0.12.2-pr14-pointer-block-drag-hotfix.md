# OpenKoto Desktop 0.12.2 PR-14.2 块拖动修复预发布版
## 发布定位
0.12.2 修复 0.12.1 中块拖动仍无法改变顺序的问题。Tauri/Wry 的原生文件拖放处理会消费 WKWebView 的 HTML5 `drop`，因此本版将编辑器内部移动改为 Pointer Events；外部文件导入继续沿用 Tauri 文件路径事件。
## 修复内容
1. 编辑器块手柄使用 Pointer capture 和 4 px 启动阈值，不再触发 HTML5 `dragstart`、`dragover` 或 `drop`。
2. 拖动时显示块前、块后的落点指示线，支持上下边缘持续自动滚动。
3. `pointercancel`、Escape、窗口失焦、离开滚动边缘和组件卸载均会清理拖动及动画状态。
4. 块移动通过单个 ProseMirror transaction 提交，撤销、重做、工具栏和 `Alt+↑/↓` 使用同一重排逻辑。
5. 移动保留块 UUID、结构属性、行内 marks 和列表项结构，保存影响只记录移动，不生成新增、修改或删除块。
6. 禁用 Tiptap 隐式尾随空段，避免标题、引用、列表或分隔线移动到末尾后产生随机 ID 空块和永久草稿状态。
## 回归覆盖
1. 26 项编辑器定向测试覆盖首尾移动、同槽位 no-op、撤销重做、取消清理、嵌套块定位和持续边缘滚动。
2. Playwright 使用真实鼠标 Pointer Events 完成两块交换，验证落点线、DOM 顺序、移动影响、保存 payload 和导入遮罩不出现。
3. PR-7 至 PR-14 历史回归、Backend、Desktop Rust、agent worker、前端、Playwright 和 packaged smoke 全部通过。
4. macOS 安装包完成 DMG 校验、深度签名校验和本机 0.12.1 覆盖升级；真实应用拖动成功并可撤销，原恢复草稿保留。
