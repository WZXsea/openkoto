# OpenKoto Desktop 0.11.0 PR-13 工程候选版

## 发布定位

0.11.0 是第一阶段工程封版候选版，用于真实安装、功能审计、页面交互调整和后续扩充决策。它保留 PR-7～PR-12 功能，不新增 Anki、Zotero、MinerU、MCP 或其他外部软件写入。

## 主要收敛

1. 将配置、Backend 认证和模型配置从 `commands.rs` 迁入独立 `app_config` 领域，13 个 Tauri command 及 DTO 保持兼容。
2. Reader 拆出顶部控制和 Assistant 外壳；Settings 拆出外观、语言、高级和日志面板。
3. Backend 启动门禁增加连接诊断和可重试错误；Assistant 时间线与产物失败可分别恢复。
4. 升级备份格式升为 v2，复制 PostgreSQL、Backend 文件库、配置和 JWT 实际字节，并通过清单、SHA-256 和 dry restore 校验。
5. 不完整 PostgreSQL 目录不会被重新初始化；Backend 迁移或健康检查失败时不提交新指纹，并返回备份恢复路径。
6. Legacy import 增加源摘要、分类计数、失败项和回执守恒检查，验证失败时明确保留源 JSON。
7. 发行流水线增加 Backend、agent-worker、Frontend 生产构建、Playwright、Apple 凭据预检和完整 `.app`/`.dmg` 签名公证门禁。

## 验证基线

1. Backend 全量数据库测试通过，包括多用户隔离、迁移、批注、学习对象、活动聚合和 Assistant 时间线。
2. agent-worker 37 项测试、Desktop Rust 103 项库测试与全部集成测试通过。
3. Frontend 59 个测试文件、232 项测试和生产构建通过。
4. Playwright 5 项通过，2 项按环境条件跳过。
5. PR-7～PR-12 历史回归链通过。

## 发行边界

本候选包使用 ad-hoc 签名，未经 Apple Developer ID 签名和公证，不得标记为第一阶段正式公开发行。正式门禁需要 Apple 证书、App Store Connect API key、双架构构建、notarization、staple 和 Gatekeeper `spctl` 全部通过。
