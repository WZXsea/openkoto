# OpenKoto Desktop 0.12.1 PR-14.1 拖放交互修复预发布版
## 发布定位
0.12.1 是 0.12.0 结构化正文编辑器的交互修复版。修复仅涉及内部块拖动与全局文件导入层的事件分流，不修改正文、版本、批注、学习项或迁移数据。
## 修复内容
1. Tiptap 块内部拖动不再触发“松开以导入”全屏遮罩。
2. Tauri `enter` 只在携带真实文件路径时激活文件导入状态。
3. `over` 只延续已确认的外部文件拖放，空路径 `drop` 被静默忽略。
4. PDF、EPUB、MD、TXT、DOCX、音视频和字幕的真实外部拖入保持可用。
## 回归覆盖
1. 应用壳层测试覆盖空路径 `enter -> over -> drop` 不显示导入层且不调用导入命令。
2. 外部 PDF `enter -> over -> leave` 仍正确显示、保持和清除导入层。
3. PR-14 结构化编辑、历史回归、生产构建和 packaged smoke 继续执行。
