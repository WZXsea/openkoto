# OpenKoto Desktop 0.12.3 PR-14.3 块手柄可达性修复预发布版
## 发布定位
0.12.3 修复 0.12.2 中光标从正文横向移向块手柄时，手柄会在光标抵达前消失的问题。0.12.2 的直接手柄坐标测试无法覆盖真实移动轨迹，本版将“正文 -> 空隙 -> 手柄”设为强制验收路径。
## 根因与修复
1. 正文左缘与手柄右缘之间存在约 6 px 空隙；旧状态机在指针离开正文时立即清除活动块。
2. 新增透明命中走廊，连续覆盖块左缘前 38 px，并覆盖当前块完整高度。
3. 正文进入走廊、走廊返回正文和走廊进入手柄均保持活动块；真正离开正文与走廊后才隐藏。
4. React 19 跨 ProseMirror DOM 边界时使用原生 `relatedTarget`，并以 `Node` 类型守卫避免 `contains` 异常。
5. 700 px 及以下窗口同步隐藏手柄和命中走廊，避免透明层拦截窄窗口操作。
## 验收证据
1. 在 0.12.2 快照中，块左缘为 `x=256`、手柄右缘为 `x=250`；鼠标从正文分步移动到空隙 `x=253` 后，手柄从 DOM 消失，强化测试明确失败。
2. 在 0.12.3 中，同一路径从正文分 10 步进入空隙、停留 50 ms，再分 4 步进入手柄，随后完整拖动、撤销、重做、影响预览和保存 payload 均通过。
3. 组件测试覆盖连续走廊、快速往返、真正离开后隐藏，以及穿越空隙后启动拖动，共 12 项通过且无未处理运行错误。
4. 前端 64 个测试文件、274 项测试，以及 Backend、Desktop Rust、agent worker、历史回归和 packaged smoke 全部通过。
5. 覆盖安装到 `/Applications/OpenKoto Desktop.app` 后，在真实桌面窗口中从段落文字移动到空隙，确认手柄仍可达；继续进入手柄并把末段拖到首段，顺序实际更新。验收后已恢复原顺序并重新保存恢复草稿。
