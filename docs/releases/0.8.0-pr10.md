# OpenKoto Desktop 0.8.0 PR-10
## 发布范围
该 Apple Silicon 个人预发布版本完成第一阶段学习对象收敛，并保持 Anki、Zotero、MinerU、LanguageTool、MCP 和浏览器插件等外部软件不接入。
## 主要变更
1. `learning_items` 成为学习内容、审核状态、原文证据和质量标记的规范对象。
2. 新增学习候选工作台，支持筛选、编辑、批量接受/拒绝/归档/恢复、标签、质量标记和重复项合并。
3. 新增 `word_pack_learning_items` 规范词包关联，并与旧 favorite/词包投影保持事务同步。
4. 新增兼容迁移的 dry-run/commit 流程，覆盖旧收藏以及已链接 legacy import 的重复覆盖。
5. 新增阅读、创建、接受、整理、合并和本地预习活动事件，以及今日/素材复盘。
6. 删除来源素材后保留所有状态的学习项和最新来源快照；合并证据、已接纳项及其投影受保护。
7. 稳定 PR-7 至 PR-9 的历史回归门禁，并补齐 GitHub Desktop Rust CI 的 agent worker 资源准备。
## 验证
1. PR-10 完整门禁：Backend、Desktop Rust、前端 typecheck/Vitest/生产构建和 2 条 Playwright 学习流程通过。
2. 历史回归：PR-9、PR-8、PR-7 全链通过。
3. Backend 数据库测试覆盖状态机、用户隔离、素材删除保留、投影同步、词包回退、legacy import 和活动幂等。
4. 本地安装前验证 `.app` 签名结构、DMG 完整性和 SHA-256；安装后验证数据库升级、登录恢复、学习项 API、复盘 API 和全栈重启。
## 平台与签名
发布资产面向 Apple Silicon macOS。该个人构建未使用 Apple Developer ID 签名和 Apple 公证；安装说明与 SHA-256 校验方法见 `docs/INSTALL_MACOS.md`。
